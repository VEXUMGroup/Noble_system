# 2026-07-16 通知ボタン位置調整

- 対象: `nobledashboard/deal-app` の認証後レイアウト
- 目的: 通知センターボタンの重複表示を解消し、サイドバー内ボタンの視認性と位置を調整する

## 変更内容

- 右側に固定表示している通知センターボタンを削除する
- サイドバーのヘッダー右上にある通知センターボタンを一回り大きくする
- サイドバー内ボタンは右端に寄りすぎないよう、少し左へ寄せる
- サイドバー内ボタンの配色は薄い青ベースに変更する

## 実装方針

- `AuthenticatedShell.tsx` の固定通知ボタンを削除する
- `Sidebar.tsx` の通知ボタンのサイズ指定クラスを拡大し、右マージンを追加する
- `Sidebar.tsx` の通知ボタンを薄い青背景・青系の枠線とアイコン色へ変更する
- 通知未読件数はボタン上部テキストではなく、右上に重なる円形バッジで表示する
- バッジ色は従来より少し明るい赤にし、白い外周リングでボタン背景との差を出す
- 未読 0 件のときはバッジを表示しない
