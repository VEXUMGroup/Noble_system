# 2026-07-16 商談中/再商談の追客入力欄拡張

## 対象
- `nobledashboard/deal-app/src/app/(authenticated)/deals/[id]/page.tsx`

## 目的
- `RS_IN_PROG`（商談中）と `RS_REDEAL`（再商談）のときに、検討理由と次回アクション日を入力しやすくする
- 次回アクション日を日付入力で選択できるようにして、後続の通知実装に使える値を確実に保存する

## 変更方針
- 既存の「検討理由」入力ブロックは `RS_PEND` / `CONSIDERING` のみに表示されているため、表示条件を `RS_IN_PROG` / `RS_REDEAL` まで広げる
- ブロック見出しは状態に応じて文言を切り替える
  - 検討: `検討理由`
  - 商談中/再商談: `追客メモ`
- 追客内容ではプルダウンによる検討理由選択は使わず、自由記述のメモ欄のみを表示する
- 次回アクション日は `input type="date"` を使い、ブラウザ標準のカレンダーピッカーを利用する
- 既存保存処理 `handleSaveResult()` の `next_action_date` / `considering_reason_comment` を利用し、追客メモはコメント欄に保存する
- 商談詳細の初期表示時に、既存値があればフォーム状態へ復元する

## 非対象
- 通知送信処理
- DBスキーマ変更
- 新規マスタ項目追加

## 確認観点
- `RS_IN_PROG` / `RS_REDEAL` を選ぶと追客メモ欄と次回アクション日が表示される
- 保存後に画面再表示しても値が残る
- `RS_PEND` / `CONSIDERING` の既存入力挙動が壊れない
