# 商談管理システム 運用マニュアル

このマニュアルは、社内の営業・管理担当者が日常的に迷わず使えるようにまとめた運用手順です。

## 1. このシステムでできること

- 商談を新規登録する
- 商談一覧を確認・検索する
- 商談の詳細を確認し、進捗を更新する
- カレンダー予定を見ながら商談化する
- 権限のある人は支払い管理・マスタ管理を行う

## 2. 利用前の準備

### 2-1. 必要なもの

- 会社から案内されたメールアドレス
- Google カレンダーの予定を連携する場合は、非公開 iCal URL
- 対応ブラウザ: Chrome 推奨

### 2-2. ログインできる条件

- `m_users` に登録されているメールアドレスであること
- 無効化されていないこと

ログインできない場合は、管理者にメールアドレスの登録状況を確認してください。

## 3. ログイン方法

1. システムのトップページを開きます。
2. メールアドレスを入力します。
3. `ログイン` ボタンを押します。
4. ログインが成功すると、商談一覧またはダッシュボードに移動します。

### ログインできないとき

- メールアドレスの入力ミスがないか確認します
- 会社から案内された正式なメールアドレスを使っているか確認します
- それでも入れない場合は、管理者に連絡します

## 4. 画面の見方

左側のメニューから主な画面を開けます。

- `商談一覧`
- `検討管理`
- `顧客管理`
- `支払い管理`  ※権限のあるユーザーのみ表示
- `マスタ管理`  ※権限のあるユーザーのみ表示

右上のユーザー表示からログアウトできます。

## 5. ダッシュボードの使い方

ダッシュボードでは、商談の概況とカレンダー予定を確認できます。

- 新規・面談待ちの件数
- 成約案件の件数
- 検討中の件数
- 今月の成約見込額
- 今後の予定

### カレンダー連携の設定

初回は `Google カレンダー未連携` またはそれに近い表示になります。

1. `iCal URL を設定する` を押します。
2. Google カレンダーの設定画面で、`非公開 iCal URL` をコピーします。
3. URL を貼り付けて `保存` を押します。
4. 予定一覧が表示されます。

### 解除・再設定

- 連携をやり直す場合は `解除` を押します
- URL を変更したい場合は `URL を変更` を押して再入力します

## 6. カレンダー予定から商談を作る

カレンダー予定をそのまま商談化できます。

### 手順

1. ダッシュボードまたは商談一覧のカレンダー欄に表示された予定を確認します。
2. 商談化したい予定をクリックします。
3. 商談登録モーダルが開きます。
4. 自動入力された内容を確認します。
5. 必要に応じて以下を修正します。
   - 顧客名
   - 担当
   - 商談日
   - 退職予定日
   - 年齢
   - メールアドレス
   - 電話番号
   - 流入経路
   - 紹介者
6. `登録する` を押します。

### 補足

- 同じ予定は一度しか商談化できません
- 登録済みの予定をもう一度登録しようとすると、重複エラーになります
- 登録が終わると、商談詳細画面へ移動します

## 7. 新規商談を手入力で登録する

カレンダー予定を使わず、通常の入力で登録することもできます。

1. `商談一覧` を開きます。
2. 右上の `+ 新規商談` を押します。
3. 必須項目を入力します。
   - お客様氏名
   - 担当
   - 商談日
   - 流入経路
   - 退職予定日
4. 必要に応じて任意項目も入力します。
5. `登録する` を押します。

登録後は商談詳細画面に遷移します。

## 8. 商談一覧の使い方

商談一覧では、案件を探したり絞り込んだりできます。

- ステータスで絞り込む
- 担当者で絞り込む
- 商談日で絞り込む
- 代理店で絞り込む
- 流入経路で絞り込む

検索条件を入れたら `検索` を押し、元に戻すときは `リセット` を押します。

## 9. 商談詳細の見方

商談詳細では、登録内容の確認や進捗更新ができます。

- 基本情報の確認
- 契約情報の確認
- 進捗の更新
- 削除

### よく使う操作

- 内容を修正したい場合は詳細画面で編集します
- 契約情報を入れる場合は、商談詳細から契約関連画面へ進みます
- 削除は取り消せないため、実行前に内容を必ず確認してください

## 10. ログアウト

右上のユーザー表示またはメニューからログアウトできます。

ログアウト後はトップページに戻ります。

## 11. よくあるトラブルと対処

### ログイン後にすぐ戻される

- セッションが切れている可能性があります
- いったん再読み込みしてから再ログインしてください

### カレンダー予定が出ない

- `iCal URL` が未設定かもしれません
- URL が正しいか確認してください
- Google カレンダー側で非公開 iCal URL が有効か確認してください

### 予定を登録できない

- 必須項目が不足している可能性があります
- `顧客名`、`担当`、`商談日`、`退職予定日` などを確認してください

### 既に商談化済みと出る

- その予定はすでに登録済みです
- 同じ予定をもう一度登録することはできません

### 支払い管理・マスタ管理が見えない

- 権限のないユーザーには表示されません
- 必要であれば管理者に権限を確認してください

## 12. 問い合わせ時に伝えるとよい情報

サポートに連絡するときは、次の情報があると対応しやすくなります。

- 自分の名前
- 画面名
- 起きた操作
- 表示されたエラーメッセージ
- 可能であればスクリーンショット
