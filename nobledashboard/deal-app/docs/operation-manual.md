# 商談管理システム 運用マニュアル

このマニュアルは、社内の営業・管理担当者が日常的に迷わず使えるようにまとめた運用手順です。
特に、ダッシュボード上の Google カレンダー連携から商談登録、商談詳細の更新までの流れを中心に説明します。

## 1. このシステムでできること

- 商談を新規登録する
- 商談一覧を確認・検索する
- 商談の詳細を確認し、進捗を更新する
- カレンダー予定を見ながら商談化する
- 権限のある人は支払い管理・マスタ管理を行う

## 2. 利用前の準備

### 2-1. 必要なもの

- 会社から案内されたメールアドレス
- Google カレンダーの予定を連携する場合は、非公開 iCal URL
- 対応ブラウザ: Chrome 推奨

### 2-2. ログインできる条件

- `m_users` に登録されているメールアドレスであること
- 無効化されていないこと

ログインできない場合は、管理者にメールアドレスの登録状況を確認してください。

## 3. ログイン方法

1. システムのトップページを開きます。
2. メールアドレスを入力します。
3. `ログイン` ボタンを押します。
4. ログインが成功すると、商談一覧またはダッシュボードに移動します。

### ログインできないとき

- メールアドレスの入力ミスがないか確認します
- 会社から案内された正式なメールアドレスを使っているか確認します
- それでも入れない場合は、管理者に連絡します

## 4. 画面の見方

左側のメニューから主な画面を開けます。

- `商談一覧`
- `検討管理`
- `顧客管理`
- `支払い管理`  ※権限のあるユーザーのみ表示
- `マスタ管理`  ※権限のあるユーザーのみ表示

右上のユーザー表示からログアウトできます。

## 5. ダッシュボードの使い方

ダッシュボードでは、商談の概況と Google カレンダー予定をまとめて確認できます。

- 新規・面談待ちの件数
- 成約案件の件数
- 検討中の件数
- 今月の成約見込額
- 今後の予定

### 5-1. Google カレンダー連携パネル

ダッシュボード上部には、Google カレンダー連携の状態が表示されます。

- `Google カレンダー連携済み`
  - 連携が完了しており、予定を取得できる状態です。
- `URL を変更`
  - 連携先の URL を変更したいときに押します。
- `解除`
  - 連携をいったん外したいときに押します。

このパネルは、カレンダー連携の状態確認と、再設定の入口になります。

### 5-2. 今後の予定一覧

`今後の予定（7日間）` には、近い日程の予定が一覧で表示されます。

- 予定のタイトル
- 開始日時
- 登録状態

表示例としては、次のような状態があります。

- `商談登録済み`
  - その予定はすでに商談として登録済みです。
- `自動登録失敗`
  - 自動登録に失敗した予定です。内容を確認して手動登録してください。

一覧右上の操作で、以下のメンテナンスができます。

- `URL変更`
  - 連携 URL を変更します。
- `解除`
  - 連携を外します。
- `更新`
  - 予定一覧を最新状態に更新します。

### 5-3. 予定を選ぶときの見方

予定の先頭にある丸印は、予定の種類を見分けやすくするための目印です。

- まずはタイトルを確認します。
- 次に開始時刻を確認します。
- 商談化したい予定かどうかを判断します。

迷った場合は、予定の説明欄や参加者情報を見てから登録してください。

## 6. カレンダー予定から商談を作る

カレンダー予定をそのまま商談化できます。登録前に内容を確認し、必要な項目だけ整えてから保存します。

### 6-1. 予定を開く

1. ダッシュボードの `今後の予定` から商談化したい予定を選びます。
2. 予定をクリックすると、`商談として登録` の画面が開きます。
3. 画面上部の `カレンダー情報` で、タイトル・説明・開始・終了を確認します。

### 6-2. 自動入力された内容を確認する

`自動入力項目（編集可）` では、予定の内容から商談用の項目が自動で入ります。

- `顧客名`
  - 予定タイトルを元に入力されます。
- `担当者`
  - ログイン中のユーザーが反映されます。
- `退職予定日`
  - 必要に応じて手入力します。
- `商談日`
  - 予定の開始日が入ります。
- `流入経路`
  - 連携設定に応じた値が入ります。

この画面では、初期値をそのまま使うことも、内容を修正することもできます。

### 6-3. 必要な項目を修正して登録する

1. 顧客名や担当者に誤りがないか確認します。
2. `退職予定日` など、手入力が必要な項目を補完します。
3. 必要に応じて `流入経路` やメモも調整します。
4. 内容を確認したら `登録` を押します。
5. 登録が完了すると、商談一覧または商談詳細に反映されます。

### 6-4. 重複登録について

同じカレンダー予定は、1 回しか商談登録できません。

- すでに登録済みの予定には `商談登録済み` が表示されます。
- 再登録しようとすると、重複登録として拒否されます。
- これは、同じ予定から商談が二重に作られるのを防ぐための仕組みです。

### 6-5. 失敗した予定の扱い

`自動登録失敗` が表示された場合は、次の流れで対応します。

1. 予定内容を開いて確認します。
2. 顧客名や説明文に不足がないか見直します。
3. 必要に応じて手入力で商談登録します。
4. それでも登録できない場合は、管理者へ相談します。

## 7. 新規商談を手入力で登録する

カレンダー予定を使わず、通常の入力で登録することもできます。

1. `商談一覧` を開きます。
2. 右上の `+ 新規商談` を押します。
3. 必須項目を入力します。
   - お客様氏名
   - 担当
   - 商談日
   - 流入経路
   - 退職予定日
4. 必要に応じて任意項目も入力します。
5. `登録する` を押します。

登録後は商談詳細画面に遷移します。

## 8. 商談一覧の使い方

商談一覧では、案件を探したり絞り込んだりできます。

- ステータスで絞り込む
- 担当者で絞り込む
- 商談日で絞り込む
- 代理店で絞り込む
- 流入経路で絞り込む

検索条件を入れたら `検索` を押し、元に戻すときは `リセット` を押します。

## 9. 商談詳細の見方

商談詳細では、登録内容の確認や進捗更新ができます。

- 基本情報の確認
- 面談結果の記録
- 成約後の契約情報入力
- 削除

### 9-1. 基本情報の確認と編集

詳細画面では、商談の基本情報を見ながら編集できます。

- 顧客名
- 電話番号
- 見込み顧客
- 流入経路
- 紹介者
- 代理店情報
- メモ

入力内容を修正したあとに `保存する` を押すと、更新内容が反映されます。

### 9-2. 面談結果を記録する

面談が終わったら、`面談結果を記録する` でステータスを更新します。

- 結果を選びます
- 必要に応じて詳細項目を入力します
- `記録する` を押します

この段階で、次のアクションにつながる情報を残しておくと、後工程がスムーズになります。

### 9-3. 成約後の契約情報を入力する

結果が `成約` の場合は、`面談結果を入力する` の下に契約関連の入力欄が表示されます。

- 成約プラン
- 支払いプラン
- 支払い方法
- 支払い期限
- イレギュラー記載

内容を確認したあと、`確定して保存` を押して登録します。

### 9-4. 画面下部の操作

詳細画面の下部には、次の操作があります。

- `戻る`
  - 前の画面へ戻ります。
- `保存する`
  - 編集内容を保存します。
- `変更を取り消す`
  - 編集をやめて、元の内容に戻します。
- `この商談を削除`
  - 商談を削除します。削除前に内容を必ず確認してください。

## 10. ログアウト

右上のユーザー表示またはメニューからログアウトできます。

ログアウト後はトップページに戻ります。

## 11. よくあるトラブルと対処

### ログイン後にすぐ戻される

- セッションが切れている可能性があります
- いったん再読み込みしてから再ログインしてください

### カレンダー予定が出ない

- 連携 URL が未設定かもしれません
- URL が正しいか確認してください
- Google カレンダー側で連携元の予定が取得できる状態か確認してください

### 予定を登録できない

- 必須項目が不足している可能性があります
- `顧客名`、`担当`、`商談日`、`退職予定日` などを確認してください

### 既に商談化済みと出る

- その予定はすでに登録済みです
- 同じ予定をもう一度登録することはできません

### 支払い管理・マスタ管理が見えない

- 権限のないユーザーには表示されません
- 必要であれば管理者に権限を確認してください

## 12. 問い合わせ時に伝えるとよい情報

サポートに連絡するときは、次の情報があると対応しやすくなります。

- 自分の名前
- 画面名
- 起きた操作
- 表示されたエラーメッセージ
- 可能であればスクリーンショット
